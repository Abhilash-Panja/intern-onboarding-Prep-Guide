# Angular Property Binding

## 1. Quick recap: Angular data binding

Data binding connects the component’s TypeScript class with its HTML template.

```text
TypeScript class → stores data and logic
HTML template    → displays the page
```

Angular has four main types of data binding:

| Type | Syntax | Purpose |
|---|---|---|
| Interpolation | `{{ value }}` | Displays data as text |
| Property binding | `[property]="value"` | Sets an element property |
| Event binding | `(event)="method()"` | Responds to user actions |
| Two-way binding | `[(ngModel)]="value"` | Keeps data and input synchronized |

This lesson focuses on property binding.

---

# 2. What is property binding?

HTML elements have properties that control their behavior.

For example:

- An image has `src` and `alt`.
- A button has `disabled`.
- An input has `value` and `placeholder`.

Property binding allows us to set these properties using values from the TypeScript class.

It uses square brackets:

```html
[property]="expression"
```

Example:

```html
<img [src]="imageUrl">
```

Angular takes the value of `imageUrl` from the component class and assigns it to the image’s `src` property.

---

# 3. Property binding is one-way

Property binding sends data in one direction:

```text
Component class → HTML element
```

For example:

```typescript
isDisabled = true;
```

```html
<button [disabled]="isDisabled">
  Submit
</button>
```

Because `isDisabled` is `true`, the button becomes disabled.

If the value changes:

```typescript
isDisabled = false;
```

Angular updates the button automatically, and it becomes clickable.

---

# 4. Interpolation vs property binding

This is the most important difference.

## Interpolation displays text

```html
<p>{{ username }}</p>
```

If:

```typescript
username = 'Abhi';
```

The page displays:

```text
Abhi
```

## Property binding controls an element property

```html
<input [value]="username">
```

The value appears inside the input field.

Remember:

```text
Interpolation    → displays text
Property binding → controls element properties
```

# 5. Example: binding image, input, and button properties

Use the same `DataBinding` component from the interpolation lesson.

## Step 1: Add data to the component class

Open `data-binding.ts`:

```typescript
export class DataBinding {
  imageUrl =
    'https://angular.dev/assets/images/press-kit/angular_icon_gradient.gif';

  imageAlt = 'Angular logo';

  placeholderText = 'Enter your name';

  isDisabled = true;
}
```

The properties are:

| Property | Type | Purpose |
|---|---|---|
| `imageUrl` | String | Stores the image location |
| `imageAlt` | String | Stores alternative text |
| `placeholderText` | String | Stores input placeholder text |
| `isDisabled` | Boolean | Controls whether the button is disabled |

---

## Step 2: Bind the properties in the template

Open `data-binding.html`:

```html
<img
  [src]="imageUrl"
  [alt]="imageAlt"
  width="100">

<input
  [placeholder]="placeholderText">

<button
  [disabled]="isDisabled">
  Submit
</button>
```

Angular performs the following connections:

```text
imageUrl        → image src
imageAlt        → image alt
placeholderText → input placeholder
isDisabled      → button disabled
```

---

## Step 3: Check the browser

You should see:

- The Angular image.
- An input with the placeholder `Enter your name`.
- A disabled Submit button.

---

## Step 4: Change the component data

Change:

```typescript
isDisabled = true;
```

to:

```typescript
isDisabled = false;
```

Save the file.

The button becomes clickable even though you did not change the HTML.

That is property binding in action:

```text
TypeScript value changes
        ↓
Angular detects the change
        ↓
HTML element property updates
```

# 6. Property binding with expressions

The value inside property binding can be an expression.

## Disable a button based on age

```typescript
age = 16;
```

```html
<button [disabled]="age < 18">
  Register
</button>
```

Because `age < 18` is `true`, the button is disabled.

If the age changes:

```typescript
age = 21;
```

The expression becomes `false`, and the button becomes enabled.

---

## Combine two values

```typescript
firstName = 'Abhi';
lastName = 'Kumar';
```

```html
<input [value]="firstName + ' ' + lastName">
```

The input displays:

```text
Abhi Kumar
```

# 7. Common mistakes

## Mistake 1: Forgetting square brackets

Incorrect:

```html
<img src="imageUrl">
```

This treats `imageUrl` as literal text.

Correct:

```html
<img [src]="imageUrl">
```

This tells Angular to use the value stored in the `imageUrl` property.

---

## Mistake 2: Mixing interpolation with property binding

Incorrect:

```html
<img [src]="{{ imageUrl }}">
```

Correct:

```html
<img [src]="imageUrl">
```

The expression already belongs inside the square brackets, so interpolation is not needed.

---

## Mistake 3: Using the wrong property name

Correct:

```html
<button [disabled]="isDisabled">
  Submit
</button>
```

Here:

- `disabled` is the HTML element property.
- `isDisabled` is the TypeScript property.

The general pattern is:

```html
[elementProperty]="componentProperty"
```

Examples:

```html
<img [src]="imageUrl">
<img [alt]="imageAlt">
<input [value]="username">
<button [disabled]="isDisabled">
```

---

## Mistake 4: Using `this` in the template

Incorrect:

```html
<p>{{ this.username }}</p>
```

Correct:

```html
<p>{{ username }}</p>
```

Use `this` inside TypeScript:

```typescript
return this.username;
```

Do not use `this` in the HTML template.

---

# 8. Interpolation and property binding: a direct comparison

```html
<!-- Interpolation: displays text -->
<p>{{ username }}</p>

<!-- Property binding: sets an element property -->
<input [value]="username">
```

Use interpolation when the value should appear as text.

Use property binding when the value should control an HTML element property.

---

# 9. Property binding is not two-way binding

Property binding sends data from the component to the element:

```text
Component → HTML element
```

If a user types something into an input, the component property does not automatically change.

For communication in both directions, Angular uses two-way binding:

```html
<input [(ngModel)]="username">
```

Two-way binding will be covered separately.

---

# 10. Quick comparison of Angular bindings

| Binding | Syntax | Direction | Example |
|---|---|---|---|
| Interpolation | `{{ }}` | Component → template | `<p>{{ username }}</p>` |
| Property binding | `[ ]` | Component → element property | `<button [disabled]="isDisabled">` |
| Event binding | `( )` | Element → component | `<button (click)="save()">` |
| Two-way binding | `[( )]` | Both directions | `<input [(ngModel)]="username">` |

# Quick revision

Property binding:

```html
[property]="expression"
```

Examples:

```html
<img [src]="imageUrl">
<input [value]="username">
<button [disabled]="isDisabled">
```

Remember:

- Square brackets indicate property binding.
- The value inside the brackets is a TypeScript expression.
- Property binding is one-way.
- Data flows from the component to the HTML element.
- Do not use `{{ }}` inside `[ ]`.
- Do not use `this.` in the HTML template.
- Use interpolation for displaying text.
- Use property binding for controlling element properties.

## One-line takeaway

> Property binding uses square brackets to connect a component value to an HTML element property.
