# Angular Event Binding

## 1. Quick recap of data binding

Angular data binding connects the component class with its HTML template.

```text
TypeScript class → data and logic
HTML template    → page content and user interaction
```

Angular has four main types of binding:

| Type | Syntax | Purpose |
|---|---|---|
| Interpolation | `{{ value }}` | Displays data as text |
| Property binding | `[property]="value"` | Sets an element property |
| Event binding | `(event)="method()"` | Responds to user actions |
| Two-way binding | `[(ngModel)]="value"` | Keeps data and input synchronized |

This lesson focuses on event binding.

---

# 2. What is event binding?

An event is an action that happens on the page.

Examples:

- User clicks a button.
- User types in an input.
- User submits a form.
- User moves the mouse over an element.
- User presses or releases a keyboard key.

Event binding allows Angular to listen for these actions and execute a method from the component class.

It uses round brackets:

```html
(event)="method()"
```

Example:

```html
<button (click)="onSave()">
  Save
</button>
```

This means:

> When the button is clicked, call the `onSave()` method.

---

# 3. Direction of event binding

Interpolation and property binding send data from the component to the page:

```text
Component → Template
```

Event binding works in the opposite direction:

```text
Template → Component
```

The complete flow is:

```text
User performs an action
        ↓
Angular detects the event
        ↓
Angular calls a component method
        ↓
The method updates data or performs an action
```

# 4. Create a simple event-binding example

Use the `DataBinding` component from the previous lessons.

## Step 1: Create a method in the component

Open `data-binding.ts`:

```typescript
export class DataBinding {
  message = '';

  onSave() {
    console.log('Button clicked!');
    this.message = 'Your data was saved.';
  }
}
```

The method does two things:

- Prints a message in the browser console.
- Updates the `message` property.

## Step 2: Bind the click event

Open `data-binding.html`:

```html
<button type="button" (click)="onSave()">
  Save
</button>

<p>{{ message }}</p>
```

## Step 3: Test the application

1. Run the application.
2. Open the browser.
3. Click the **Save** button.
4. Open the browser developer tools with `F12`.
5. Check the **Console** tab.

After clicking the button:

- The console shows `Button clicked!`.
- The page displays `Your data was saved.`.

The event flow is:

```text
Button click
    ↓
(click)="onSave()"
    ↓
onSave()
    ↓
message changes
    ↓
{{ message }} displays the new value
```

# 5. Reading user input with `$event`

Sometimes we need information about the event itself.

For example:

- What did the user type?
- Which key did the user press?
- Which option did the user select?

Angular provides a special variable called `$event`.

`$event` contains information about the event that occurred.

## Component class

```typescript
export class DataBinding {
  message = '';

  onTyping(event: Event) {
    const input = event.target as HTMLInputElement;
    this.message = input.value;
  }
}
```

## Template

```html
<input
  type="text"
  placeholder="Type something"
  (input)="onTyping($event)">

<p>You typed: {{ message }}</p>
```

## What happens?

```text
1. The user types a character.
2. The input event occurs.
3. Angular calls onTyping($event).
4. The method reads the input value.
5. The message property is updated.
6. Interpolation displays the updated message.
```

This example combines two types of binding:

```html
(input)="onTyping($event)"
```

This is event binding.

```html
{{ message }}
```

This is interpolation.

# 6. Passing your own value to a method

You can pass a specific value to a method when the event occurs.

## Template

```html
<button
  type="button"
  (click)="greet('Abhi')">
  Say Hello
</button>
```

## Component class

```typescript
greet(name: string) {
  console.log('Hello ' + name);
}
```

When the button is clicked, the console displays:

```text
Hello Abhi
```

The value `'Abhi'` is passed directly to the `greet()` method.

# 7. Common events

| Event | When it occurs |
|---|---|
| `(click)` | User clicks an element |
| `(input)` | User types or changes input text |
| `(change)` | A value changes, such as a selected option |
| `(submit)` | A form is submitted |
| `(mouseover)` | The mouse moves over an element |
| `(keyup)` | The user releases a keyboard key |

Example:

```html
<input (keyup)="onKeyUp()">
```

```html
<select (change)="onCourseChange()">
  <option>Angular</option>
  <option>TypeScript</option>
</select>
```

# 8. Common mistakes

## Mistake 1: Using square brackets instead of round brackets

Incorrect:

```html
<button [click]="onSave()">
  Save
</button>
```

Correct:

```html
<button (click)="onSave()">
  Save
</button>
```

Remember:

```text
[ ] → property binding
( ) → event binding
```

---

## Mistake 2: Writing `onclick`

Incorrect:

```html
<button (onclick)="onSave()">
  Save
</button>
```

Correct:

```html
<button (click)="onSave()">
  Save
</button>
```

In Angular, write only the event name inside the brackets.

```text
HTML style: onclick
Angular style: (click)
```

---

## Mistake 3: Forgetting the method parentheses

Incorrect:

```html
<button (click)="onSave">
  Save
</button>
```

Correct:

```html
<button (click)="onSave()">
  Save
</button>
```

The parentheses call the method when the event occurs.

---

## Mistake 4: Using `this` in the template

Incorrect:

```html
<button (click)="this.onSave()">
  Save
</button>
```

Correct:

```html
<button (click)="onSave()">
  Save
</button>
```

Do not use `this.` in Angular templates.

# 9. Event binding and other bindings together

Real Angular applications commonly use multiple types of binding together.

```typescript
export class Counter {
  count = 0;

  increase() {
    this.count++;
  }

  decrease() {
    if (this.count > 0) {
      this.count--;
    }
  }

  reset() {
    this.count = 0;
  }
}
```

```html
<h2>Count: {{ count }}</h2>

<button type="button" (click)="increase()">
  Increase
</button>

<button
  type="button"
  [disabled]="count === 0"
  (click)="decrease()">
  Decrease
</button>

<button type="button" (click)="reset()">
  Reset
</button>
```

This example uses:

```text
{{ count }}           → interpolation
[disabled]="..."      → property binding
(click)="..."         → event binding
```

# 10. Event binding and backend communication

Event binding itself does not send data to a backend.

It only calls a method:

```html
<button (click)="onSave()">
  Save
</button>
```

The method can later call a service:

```typescript
onSave() {
  // Prepare data
  // Call a service
  // Send data to an API
}
```

The general flow is:

```text
User clicks Save
        ↓
Event binding calls onSave()
        ↓
Component prepares the data
        ↓
A service can send the data to an API
```

Backend communication is a separate topic. For now, practise by updating properties and using `console.log()`.

# 11. Quick comparison of Angular bindings

| Binding | Syntax | Direction | Purpose |
|---|---|---|---|
| Interpolation | `{{ }}` | Component → template | Display text |
| Property binding | `[ ]` | Component → element | Set element properties |
| Event binding | `( )` | Template → component | Respond to user actions |
| Two-way binding | `[( )]` | Both directions | Keep data and inputs synchronized |

# Quick revision

Event binding allows Angular to respond to user actions.

Syntax:

```html
(event)="method()"
```

Example:

```html
<button (click)="onSave()">
  Save
</button>
```

Remember:

- Event binding uses round brackets.
- The event calls a method in the component class.
- Use `$event` when you need information about the event.
- Do not use square brackets for events.
- Do not write `onclick`; use `(click)`.
- Do not use `this.` inside the template.
- Event binding sends control from the template to the component.

## One-line takeaway

> Event binding uses round brackets to listen for user actions and call methods in the Angular component.
