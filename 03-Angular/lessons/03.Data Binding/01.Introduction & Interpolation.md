# Angular Data Binding: Interpolation

## 1. What is data binding?

An Angular component usually has two important files:

```text
TypeScript file (.ts) → data and behavior
HTML file (.html)     → content displayed on the screen
```

Data binding connects these two files.

For example, the TypeScript class can contain:

```typescript
course = 'Angular Basics';
```

The HTML template can display it:

```html
<p>Course: {{ course }}</p>
```

The browser displays:

```text
Course: Angular Basics
```

Without data binding, we would have to manually find HTML elements and update their content whenever the data changed. Angular handles this connection for us.

---

## 2. Types of Angular data binding

Angular mainly provides four types of data binding:

| Type | Syntax | Purpose |
|---|---|---|
| Interpolation | `{{ value }}` | Displays component data as text |
| Property binding | `[property]="value"` | Sets an HTML property |
| Event binding | `(event)="method()"` | Responds to user actions |
| Two-way binding | `[(ngModel)]="value"` | Keeps data and input synchronized |

In this lesson, we focus on interpolation.

```text
Interpolation = Display TypeScript data in HTML
```

---

# 3. What is interpolation?

Interpolation displays a value from the component class inside the HTML template.

It uses double curly braces:

```html
{{ expression }}
```

Example:

```typescript
studentName = 'Abhi';
```

```html
<h2>Student Name: {{ studentName }}</h2>
```

Output:

```text
Student Name: Abhi
```

Angular evaluates the expression inside `{{ }}` and displays the result as text.

# 5. Add data in the TypeScript file

Open `data-binding.ts`:

```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-data-binding',
  templateUrl: './data-binding.html',
  styleUrl: './data-binding.css'
})
export class DataBinding {
  firstName = 'Abhi';
  lastName = 'Kumar';
  course = 'Angular Basics';

  age = 21;
  marks1 = 78;
  marks2 = 85;
  marks3 = 92;

  getGreeting() {
    return 'Welcome to the class!';
  }

  getFullName() {
    return this.firstName + ' ' + this.lastName;
  }
}
```

## Understanding the properties

```typescript
firstName = 'Abhi';
age = 21;
```

TypeScript automatically understands the types from the assigned values. This is called type inference.

```text
firstName → string
age       → number
marks1    → number
```

Inside the TypeScript class, use `this` to access class properties:

```typescript
this.firstName
```

Inside the HTML template, do not use `this`:

```html
{{ firstName }}
```

# 6. Display data in the HTML template

Open `data-binding.html`:

```html
<h2>Student Details</h2>

<p>First Name: {{ firstName }}</p>
<p>Last Name: {{ lastName }}</p>
<p>Course: {{ course }}</p>
<p>Age: {{ age }}</p>
```

The output will be:

```text

First Name: Abhi
Last Name: Kumar
Course: Angular Basics
Age: 21
```

The connection is:

```text
firstName = 'Abhi'
        ↓
{{ firstName }}
        ↓
First Name: Abhi
```

# 7. Display the component in the application

Creating a component does not automatically display it. We must use the component inside another component.

## Step 1: Import the component

Open the root component, usually `app.ts`:

```typescript
import { Component } from '@angular/core';
import { DataBinding } from './data-binding/data-binding';

@Component({
  selector: 'app-root',
  imports: [DataBinding],
  templateUrl: './app.html'
})
export class App {
}
```

This part makes the component available:

```typescript
imports: [DataBinding]
```

## Step 2: Use the component selector

Open `app.html`:

```html
<h1>Angular Data Binding</h1>

<app-data-binding></app-data-binding>
```

The selector comes from `data-binding.ts`:

```typescript
selector: 'app-data-binding'
```

That selector is used as an HTML element:

```html
<app-data-binding></app-data-binding>
```

## Complete flow

```text
index.html
    ↓
<app-root>
    ↓
app.html
    ↓
<app-data-binding>
    ↓
data-binding.html
    ↓
Interpolation displays the data
```

The root element is normally present in `index.html`:

```html
<body>
  <app-root></app-root>
</body>
```

# 9. What can be used inside interpolation?

Interpolation can display more than simple property values.

## 9.1 Display a property

```html
<p>{{ course }}</p>
```

Output:

```text
Angular Basics
```

---

## 9.2 Combine values

```html
<h2>{{ firstName + ' ' + lastName }}</h2>
```

Output:

```text
Abhi Kumar
```

---

## 9.3 Perform calculations

```html
<p>Total Marks: {{ marks1 + marks2 + marks3 }}</p>

<p>
  Average Marks:
  {{ (marks1 + marks2 + marks3) / 3 }}
</p>
```

Output:

```text
Total Marks: 255
Average Marks: 85
```

---

## 9.4 Call a method

```html
<p>{{ getGreeting() }}</p>
```

Output:

```text
Welcome to the class!
```

The method must return a value that Angular can display.

---

## 9.5 Use a condition

```html
<p>{{ age >= 18 ? 'Adult' : 'Minor' }}</p>
```

Output:

```text
Adult
```

This is called the ternary operator.

It means:

```text
If age is 18 or greater → Adult
Otherwise                → Minor
```

---

## 9.6 Use a string method

```html
<p>{{ firstName.toUpperCase() }}</p>
```

Output:

```text
ABHI
```

# 10. Important method mistake

Consider this method:

```typescript
displayDetails(): void {
  console.log(this.firstName + ' ' + this.lastName);
}
```

If you use it in the template:

```html
<p>{{ displayDetails() }}</p>
```

Nothing appears on the page.

## Why?

The method returns `void`, which means it does not return a value.

Also:

```typescript
console.log(...)
```

prints only in the browser developer console. It does not display text in the HTML page.

## Correct approach

Return the value from the method:

```typescript
getFullName(): string {
  return this.firstName + ' ' + this.lastName;
}
```

Use it in the template:

```html
<p>Full Name: {{ getFullName() }}</p>
```

Now the page displays:

```text
Full Name: Abhi Kumar
```

Remember:

```text
console.log() → prints in the developer console
return        → gives a value back to the template
```

# 11. What interpolation can and cannot do

## Interpolation can:

- Display component properties
- Combine strings
- Perform simple calculations
- Call methods that return values
- Use simple expressions
- Use the ternary operator

## Interpolation cannot directly contain statements such as:

```typescript
if
for
while
x = 5
```

For conditional rendering, use Angular control flow:

```html
@if (age >= 18) {
  <p>Adult</p>
}
```

For lists, use:

```html
@for (mark of marks; track mark) {
  <p>{{ mark }}</p>
}
```

# 12. What happens when data changes?

Suppose the component initially contains:

```typescript
course = 'Angular Basics';
```

The page displays:

```text
Angular Basics
```

If you change the value to:

```typescript
course = 'Advanced Angular';
```

The page displays:

```text
Advanced Angular
```

You do not need to manually search for the HTML element and update it. Angular connects the data to the template and refreshes the displayed value.

```text
Component data changes
        ↓
Angular detects the change
        ↓
Template is updated
        ↓
Browser shows the new value
```

# 13. Practice task: Student Profile Card

Create a component that displays:

1. Student full name
2. Course name
3. Age
4. Total marks
5. Average marks
6. A greeting returned from a method
7. `Pass` or `Fail` based on the average

Example TypeScript data:

```typescript
firstName = 'Abhi';
lastName = 'Kumar';
course = 'Angular Basics';
age = 21;

marks1 = 78;
marks2 = 85;
marks3 = 92;

getTotalMarks() {
  return this.marks1 + this.marks2 + this.marks3;
}

getAverageMarks() {
  return this.getTotalMarks() / 3;
}

getGreeting() {
  return 'Welcome to Angular learning!';
}
```

Example template:

```html
<h2>Student Profile</h2>

<p>Name: {{ firstName + ' ' + lastName }}</p>
<p>Course: {{ course }}</p>
<p>Age: {{ age }}</p>
<p>Total Marks: {{ getTotalMarks() }}</p>
<p>Average Marks: {{ getAverageMarks() }}</p>
<p>{{ getGreeting() }}</p>

<p>
  Result:
  {{ getAverageMarks() >= 40 ? 'Pass' : 'Fail' }}
</p>
```

Then change one of the marks in the TypeScript file and observe how the total, average, and result change automatically.

# Quick revision

```text
Data binding connects TypeScript data with an HTML template.
```

Interpolation uses:

```html
{{ expression }}
```

Example:

```typescript
name = 'Abhi';
```

```html
<p>Hello, {{ name }}</p>
```

Output:

```text
Hello, Abhi
```

Remember:

- Use `this.name` inside TypeScript.
- Use `name` inside the HTML template.
- Interpolation displays values as text.
- A method used in interpolation should return a value.
- `console.log()` displays information in the browser console, not on the page.
- Angular automatically updates the template when bound data changes.

## One-line takeaway

> Interpolation uses `{{ }}` to display component data and expression results inside an Angular HTML template.
