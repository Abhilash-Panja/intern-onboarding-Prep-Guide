# Angular Property Binding for Beginners

*Part 2 of my Angular data binding series*

In the previous post, I learned about **interpolation**, which shows data from the TypeScript file as text in the HTML. In this post, I'll explain the next type of data binding: **property binding**. It is just as simple, and it makes your pages much more dynamic.

## 1. A Quick Recap

Data binding is the connection between the TypeScript file (`.ts`), which holds the data, and the HTML file (`.html`), which shows the page.

Angular has four types:

1. Interpolation `{{ }}`
2. Property binding `[ ]`
3. Event binding `( )`
4. Two-way binding `[( )]`

Today's topic is number 2.

## 2. What Is Property Binding?

Every HTML element has **properties**. For example:

- An image has `src` (where the picture comes from) and `alt` (description text).
- A button has `disabled` (whether it can be clicked or not).
- An input has `placeholder` and `value`.

**Property binding lets you set these properties using data from your TypeScript file.** You do this by putting the property name inside square brackets `[ ]`.

```html
<img [src]="imageUrl" />
```

Here, Angular takes the value of `imageUrl` from the `.ts` file and gives it to the image's `src` property.

Property binding is **one-way binding**. Data flows from the `.ts` file to the HTML, never the other way around. If the data changes in the `.ts` file, the element updates automatically.

## 3. Interpolation vs Property Binding

This is the part that confused me at first, so here is a simple way to think about it:

- **Interpolation (`{{ }}`)** puts a value into the text of an element.
- **Property binding (`[ ]`)** sets a property of an element.

```html
<!-- Interpolation: shows text on the page -->
<p>{{ username }}</p>

<!-- Property binding: sets a property of the input -->
<input [value]="username" />
```

In the first line, the name appears as text. In the second line, the name is placed inside the input box.

## 4. How to Use Property Binding: Step by Step

### Step 1: Add Data in the TypeScript File

Open `data-binding.ts` and add some properties:

```typescript
export class DataBinding {
  imageUrl = 'https://angular.dev/assets/images/press-kit/angular_icon_gradient.gif';
  imageAlt = 'Angular logo';
  placeholderText = 'Enter your name';
  isDisabled = true;
}
```

TypeScript works out the types on its own:

- `imageUrl`, `imageAlt`, and `placeholderText` are strings.
- `isDisabled` is a boolean.

### Step 2: Bind the Properties in the HTML File

Open `data-binding.html` and use square brackets:

```html
<img [src]="imageUrl" [alt]="imageAlt" width="100" />

<input [placeholder]="placeholderText" />

<button [disabled]="isDisabled">Submit</button>
```

### Step 3: Check the Browser

You should see:

- The Angular logo loaded from `imageUrl`.
- An input box showing the placeholder "Enter your name".
- A **disabled** Submit button that you can't click.

### Step 4: Change the Data and Watch the Page

Go back to the `.ts` file and change:

```typescript
isDisabled = true;
```

to:

```typescript
isDisabled = false;
```

Save the file. The button becomes clickable without you touching the HTML.

That is data binding at work.

## 5. Using Expressions

Just like interpolation, you can write expressions inside property binding:

```html
<button [disabled]="age < 18">Register</button>

<input [value]="firstName + ' ' + lastName" />
```

- The Register button is disabled when the age is below 18.
- The input shows the full name.

## 6. Common Mistakes to Avoid

### Mistake 1: Forgetting the Square Brackets

```html
<!-- Wrong: treats imageUrl as literal text -->
<img src="imageUrl" />

<!-- Correct: uses the variable from the .ts file -->
<img [src]="imageUrl" />
```

Without the brackets, Angular doesn't evaluate `imageUrl` as a component expression. It treats the value as a literal HTML attribute.

### Mistake 2: Mixing Interpolation with Property Binding

```html
<!-- Wrong -->
<img [src]="{{ imageUrl }}" />

<!-- Correct -->
<img [src]="imageUrl" />
```

Inside `[ ]`, the quotes already hold a TypeScript expression, so you don't need `{{ }}`.

### Mistake 3: Using the Wrong Property Name

The name inside the brackets is the element's **property**, such as:

- `[disabled]`
- `[src]`
- `[value]`
- `[hidden]`

Your editor will usually warn you if the property doesn't exist.

## 7. Rules to Remember

- Property binding uses **square brackets** `[ ]` around the property name.
- The value in quotes is a **TypeScript expression**, so it can use variables, calculations, and conditions.
- It is **one-way**: from the `.ts` file to the HTML element.
- Don't use `{{ }}` inside `[ ]`.
- Don't write `this.` in the HTML file.

## 8. Quick Comparison of All Four Bindings

| Binding | Syntax | Direction | Used for |
|---|---|---|---|
| Interpolation | `{{ }}` | Component to page | Showing text |
| Property binding | `[ ]` | Component to element | Setting element properties |
| Event binding | `( )` | Page to component | Reacting to clicks and actions |
| Two-way binding | `[( )]` | Both ways | Keeping inputs and data in sync |

## 10. Summary

- **Property binding** sets the properties of HTML elements using data from the `.ts` file.
- It uses **square brackets** `[ ]`, for example `[src]`, `[disabled]`, and `[value]`.
- It is **one-way binding**, from the component to the page.
- Interpolation is for **displaying text**, while property binding is for **setting element properties**.

Next up is **event binding**, where the page starts reacting to button clicks and other user actions.
