# Angular Data Binding for Beginners: Understanding Interpolation

## 1. What Is Data Binding?

Every Angular component has two parts:

- **TypeScript file (`.ts`):** Holds the data and logic, such as a student's name or marks.
- **HTML file (`.html`):** Holds what the user sees on the screen.

**Data binding is the connection between these two files.** It lets the HTML display data from the TypeScript file and keeps the page up to date automatically when that data changes.

Without data binding, you would have to find each element on the page and change its text yourself every time something changed. With data binding, you change the data, and Angular updates the page for you.

## 2. Types of Data Binding

Angular has four main types of data binding:

1. **Interpolation (`{{ }}`):** Shows data from the `.ts` file as text in the HTML.
2. **Property binding (`[ ]`):** Sets the properties of HTML elements using data, such as an image source or whether a button is disabled.
3. **Event binding (`( )`):** Lets the page react to user actions, like a button click.
4. **Two-way binding (`[( )]`):** Keeps the data and an input field in sync in both directions.

The first three move data in one direction or react to the user. Two-way binding combines them.

In this post, we'll focus on the first one, **interpolation**, because it's the best place to start.

## 3. What Is Interpolation?

Interpolation means displaying a value from your TypeScript class inside your HTML using double curly braces:

```html
{{ something }}
```

Whatever is inside the braces is evaluated by Angular, and the result is shown on the page as text.

## 4. How to Use Interpolation: Step by Step

### Step 1: Create a Component

In the terminal, inside your Angular project, run:

```bash
ng generate component data-binding
```

This creates a folder with four files:

- `data-binding.ts`
- `data-binding.html`
- `data-binding.css`
- `data-binding.spec.ts`

**Tip:** On Windows PowerShell, if you get a "running scripts is disabled" error, use:

```powershell
ng.cmd generate component data-binding
```

Alternatively, you can run the following command once:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Step 2: Add Data in the TypeScript File

Open `data-binding.ts` and add some properties inside the class:

```typescript
export class DataBinding {
  firstName = 'Abhi';
  lastName = 'Kumar';
  course = 'Angular Basics';
  age = 21;
  marks1 = 78;
  marks2 = 85;
  marks3 = 92;

  getGreeting() {
    return 'Welcome to the class!';
  }
}
```

You don't need to write the data type for these properties. TypeScript works it out from the value, which is called **type inference**.

For example:

- `course` is a string.
- `age` is a number.

### Step 3: Show the Data in the HTML File

Open `data-binding.html` and use `{{ }}` to display the values:

```html
<p>Course: {{ course }}</p>
<p>Age: {{ age }}</p>
```

The page will now show:

```text
Course: Angular Basics
Age: 21
```

In the HTML, you write just `course`, not `this.course`. The `this.` keyword is used inside the TypeScript class to refer to its properties and methods.

### Step 4: Make the Component Appear on the Page

Creating a component isn't enough. You need to connect it to the root component in three small steps.

**1. Import the component in `app.ts`.**

Import the component and add it to the `imports` array:

```typescript
import { DataBinding } from './data-binding/data-binding';

@Component({
  imports: [RouterOutlet, DataBinding],
  // ...
})
```

Keep the other existing code in your `app.ts` file.

**2. Add the component's tag in `app.html`.**

```html
<app-data-binding />
```

The tag name comes from the selector in the component file, which is `app-data-binding`.

**3. Keep `index.html` simple.**

It should contain the root component tag:

```html
<body>
  <app-root></app-root>
</body>
```

The flow is:

```text
index.html
    |
    v
<app-root>
    |
    v
app.html
    |
    v
<app-data-binding />
    |
    v
data-binding.html
    |
    v
Displays the data
```

### Step 5: Run the Application

Run the application using:

```bash
ng serve
```

Then open the following URL in your browser:

[http://localhost:4200](http://localhost:4200)

If you see "Port 4200 is already in use", an old development server may still be running.

You can either:

- Stop the existing server using `Ctrl + C`.
- Run the application on another port:

```bash
ng serve --port 4300
```

## 5. What Can You Write Inside `{{ }}`?

Interpolation can do more than display plain values. Here are some useful examples.

### 5.1 Combine Values

```html
<h2>{{ firstName + ' ' + lastName }}</h2>
```

Output:

```text
Abhi Kumar
```

### 5.2 Do Calculations

```html
<p>Total: {{ marks1 + marks2 + marks3 }}</p>

<p>Average: {{ (marks1 + marks2 + marks3) / 3 }}</p>
```

Output:

```text
Total: 255
Average: 85
```

### 5.3 Call a Method

```html
<p>{{ getGreeting() }}</p>
```

Output:

```text
Welcome to the class!
```

### 5.4 Use a Condition (Ternary Operator)

```html
<p>{{ age >= 18 ? 'Adult' : 'Minor' }}</p>
```

Output:

```text
Adult
```

### 5.5 Use String Methods

```html
<p>{{ firstName.toUpperCase() }}</p>
```

Output:

```text
ABHI
```

## 6. A Common Mistake: Methods That Return Nothing

I made this mistake myself. I wrote a method like this:

```typescript
displayDetails(): void {
  console.log(this.firstName + ' ' + this.lastName);
}
```

Then I used it in the HTML:

```html
{{ displayDetails() }}
```

The page showed nothing.

### Why Did This Happen?

Interpolation displays the return value of an expression.

This method returns nothing (`void`), and `console.log()` only prints to the browser's developer console, not to the page. You can open the console by pressing `F12`.

### The Fix: Return the Value

Instead of printing the value to the console, return it from the method:

```typescript
getFullName(): string {
  return this.firstName + ' ' + this.lastName;
}
```

Then use it in the HTML:

```html
<p>Full name: {{ getFullName() }}</p>
```

Now the page shows:

```text
Full name: Abhi Kumar
```

**Remember:** If you want interpolation to display a method's result, the expression must produce a value.

## 7. Rules to Remember

- Interpolation is used to display values as text.
- A method used inside `{{ }}` should return a value if you want to display its result.
- You can't write statements like `if`, `for`, or `x = 5` inside interpolation. You can use expressions that produce a value.
- Don't use `this.` in the HTML template to access component properties.
- When you change data in the `.ts` file, Angular updates the displayed value automatically.

That is the real power of data binding!

## 9. Summary

- Data binding connects your TypeScript data to your HTML page.
- Angular has four types of data binding: interpolation, property binding, event binding, and two-way binding.
- Interpolation uses `{{ }}` to display values, calculations, and method results as text.
- To use interpolation, create a component, add data in the `.ts` file, display it using `{{ }}` in the `.html` file, and connect the component to `app.ts` and `app.html`.
