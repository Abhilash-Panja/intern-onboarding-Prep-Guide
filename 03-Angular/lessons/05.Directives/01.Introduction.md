# Angular Directives

## 1. What is an HTML attribute?

An HTML attribute provides additional information about an element.

Example:

```html
<img
  src="profile.jpg"
  alt="Student profile picture">
```

Here:

- `src` tells the browser where the image is located.
- `alt` provides alternative text.

Attributes can also affect an element’s appearance or behavior.

---

# 2. What is an Angular directive?

An Angular directive is a class that adds extra behavior, appearance, or structure to an HTML element.

A simple way to remember it is:

```text
Directive = Instructions that tell Angular how an element should behave
```

Directives are often used through HTML-like syntax, so they can look similar to custom HTML attributes.

However, an Angular directive is more than a normal HTML attribute. It contains Angular logic that can change an element or the DOM.

---

# 3. Types of Angular directives

Angular directives are commonly divided into three types:

```text
1. Component directives
2. Attribute directives
3. Structural directives
```

## Quick comparison

| Type | Main responsibility | Examples |
|---|---|---|
| Component | Defines a reusable UI section | `@Component` |
| Attribute directive | Changes appearance or behavior | `ngClass`, `ngStyle`, `ngModel` |
| Structural directive | Changes the structure of the DOM | `*ngIf`, `*ngFor`, `*ngSwitchCase` |

A useful memory trick:

```text
Structural directive → What exists on the page?
Attribute directive  → How does it look or behave?
Component            → What reusable UI section should be displayed?
```

---

# 4. Structural directives

Structural directives change the structure of the HTML.

They can:

- Add elements
- Remove elements
- Repeat elements
- Choose between different elements

Structural directives usually use the `*` symbol in older Angular syntax.

---

## 4.1 `*ngIf`

`*ngIf` displays an element only when a condition is true.

### Component class

```typescript
isLoggedIn = true;
```

### Template

```html
<p *ngIf="isLoggedIn">
  Welcome back!
</p>
```

If `isLoggedIn` is `true`, Angular displays the paragraph.

If it is `false`, Angular removes the paragraph from the DOM.

### With `else`

```html
@if (isLoggedIn) {
  <p>Welcome back!</p>
} @else {
  <p>Please log in.</p>
}
```

Modern Angular projects generally use `@if`. Older Angular tutorials commonly use:

```html
<p *ngIf="isLoggedIn; else loginMessage">
  Welcome back!
</p>

<ng-template #loginMessage>
  <p>Please log in.</p>
</ng-template>
```

---

## 4.2 `*ngFor`

`*ngFor` repeats an element for every item in a collection.

### Component class

```typescript
tasks = [
  'Learn Angular',
  'Build a component',
  'Practise data binding'
];
```

### Older template syntax

```html
<ul>
  <li *ngFor="let task of tasks">
    {{ task }}
  </li>
</ul>
```

Angular creates one `<li>` element for each task.

### Modern Angular syntax

```html
<ul>
  @for (task of tasks; track task) {
    <li>{{ task }}</li>
  }
</ul>
```

The `track` expression helps Angular identify each item efficiently.

---

## 4.3 `ngSwitch`

`ngSwitch` displays one block based on a selected value.

### Component class

```typescript
role = 'admin';
```

### Older syntax

```html
<div [ngSwitch]="role">
  <p *ngSwitchCase="'admin'">
    Admin dashboard
  </p>

  <p *ngSwitchCase="'user'">
    User dashboard
  </p>

  <p *ngSwitchDefault>
    Guest dashboard
  </p>
</div>
```

### Modern syntax

```html
@switch (role) {
  @case ('admin') {
    <p>Admin dashboard</p>
  }

  @case ('user') {
    <p>User dashboard</p>
  }

  @default {
    <p>Guest dashboard</p>
  }
}
```

# 5. Attribute directives

Attribute directives do not usually add or remove elements.

Instead, they change an existing element’s:

- Appearance
- Style
- Behavior
- State

They are used on an existing HTML element.

---

## 5.1 `ngClass`

`ngClass` adds or removes CSS classes dynamically.

### Component class

```typescript
isActive = true;
```

### Template

```html
<div [ngClass]="{ active: isActive }">
  Student Profile
</div>
```

If `isActive` is `true`, Angular applies the `active` class.

Example CSS:

```css
.active {
  color: green;
  font-weight: bold;
}
```

---

## 5.2 `ngStyle`

`ngStyle` applies styles dynamically.

### Component class

```typescript
textColor = 'blue';
fontSize = '20px';
```

### Template

```html
<p
  [ngStyle]="{
    color: textColor,
    'font-size': fontSize
  }">
  Angular Learning
</p>
```

Angular applies the values stored in the component class.

---

## 5.3 `ngModel`

`ngModel` connects form controls with component data.

```html
<input [(ngModel)]="username">

<p>Hello, {{ username }}</p>
```

When the user types in the input, the `username` property updates automatically.

When the `username` property changes, the input updates as well.

This is called two-way binding.

To use `ngModel`, import `FormsModule`:

```typescript
import { FormsModule } from '@angular/forms';

@Component({
  imports: [FormsModule]
})
```

---

# 6. Component directives

A component is a special type of directive that has its own:

- HTML template
- TypeScript class
- CSS styles
- Selector

Example:

```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-task-list',
  templateUrl: './task-list.html',
  styleUrl: './task-list.css'
})
export class TaskList {
}
```

The selector is:

```typescript
selector: 'app-task-list'
```

We use it in another template like this:

```html
<app-task-list></app-task-list>
```

This displays the complete `TaskList` component.

Unlike an attribute directive, a component normally represents a complete reusable section of the user interface.

---

# 7. Difference between the three directive types

## Structural directive

Changes what exists in the DOM.

```html
@if (isLoggedIn) {
  <p>Welcome</p>
}
```

## Attribute directive

Changes how an existing element looks or behaves.

```html
<div [ngClass]="{ active: isActive }"></div>
```

## Component directive

Defines a complete reusable UI section.

```html
<app-task-list></app-task-list>
```

---

# 8. Important version note

Older Angular tutorials commonly use:

```html
*ngIf
*ngFor
[ngSwitch]
*ngSwitchCase
```

Modern Angular projects also support built-in control-flow syntax:

```html
@if
@for
@switch
```

Both styles are related to controlling the structure of the template. Follow the syntax used by your Angular project and course.
