### 3.4 Lifecycle Execution Order

For a component created and later destroyed, observe these selected events:

```text
constructor()
    ↓
ngOnInit()
    ↓
ngAfterViewInit()
    ↓
ngOnDestroy()
```

> This is a simplified sequence showing only the selected hooks; Angular has other lifecycle stages.

**Hands-on:** Implement all three hooks in one component and observe console output as it is created and removed.

### 5.2 Primitive Types in TypeScript

| Primitive type | Example        | Purpose                        |
| -------------- | -------------- | ------------------------------ |
| `string`       | `"Rahul"`      | Text values                    |
| `number`       | `25`           | Numeric values                 |
| `boolean`      | `true`         | True/false values              |
| `undefined`    | `undefined`    | Missing or uninitialized value |
| `null`         | `null`         | Intentionally empty value      |
| `bigint`       | `123n`         | Large integers                 |
| `symbol`       | `Symbol("id")` | Unique identifiers             |

Also introduce `any`, `unknown`, and `void` as important TypeScript types, while clarifying that they are **not additional JavaScript primitive types**.
