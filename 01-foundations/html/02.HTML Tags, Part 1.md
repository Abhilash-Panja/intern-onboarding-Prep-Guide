**Goal:** Use the right HTML tags to create clear, meaningful page content.  
**Prerequisite:** [Day 1 — HTML Fundamentals](day-01-html-fundamentals.md).  
**Suggested time:** 60–90 minutes, including practice.

## 1. Why do the right tags matter?

Compare:

```html
<p><b>Clinic Opening Hours</b></p>
<h2>Clinic Opening Hours</h2>
```

Both may appear bold. But the second is a **real section heading**. Choosing tags by meaning is called **semantic HTML**.

This matters for three reasons:

- **Accessibility:** Good structure helps people navigate pages, including people using screen readers. It is one part of accessibility, not a complete solution.
- **Semantics:** Tags communicate whether content is a heading, paragraph, warning, and so on.
- **SEO (Search Engine Optimization):** Clear titles, headings, and useful content help search engines understand a page. They **do not guarantee** higher rankings.

**Rule:** Use HTML for meaning. Use CSS later for visual style.

## 2. Attributes and page information

Attributes provide extra information about an element. For example:

```html
<html lang="en">
```

`lang="en"` tells software that the document's primary language is English. The language should match the actual content.

Three useful elements inside `head`:

```html
<meta charset="UTF-8">
<meta name="description" content="Clinic hours and visitor information.">
<title>Visitor Information | Demo Clinic</title>
```

- **`charset`:** Declares text encoding so characters are interpreted correctly.
- **Meta description:** Summarizes a page; search engines *may* use it in results.
- **`title`:** Gives the page a meaningful browser-tab title and may influence its search-result title.

Also keep `<!DOCTYPE html>` at the top of your document to trigger standards mode.

## 3. Essential content tags

### Headings and paragraphs

| Tag | Use it for |
| --- | --- |
| `<h1>`–`<h6>` | Headings from highest to lowest level, **not** simply different font sizes |
| `<p>` | A paragraph of text |
| `<br>` | A meaningful line break *inside* content, such as an address or poem |
| `<hr>` | A thematic change between parts of a page; browsers often draw a line |

Example of a sensible heading hierarchy:

```html
<h1>Clinic Information</h1>
<h2>Opening Hours</h2>
<p>Monday to Friday, 9 AM to 5 PM.</p>
<h2>Services</h2>
<h3>General Consultation</h3>
<p>Appointments are available on weekdays.</p>
```

### Meaning within text

| Tag | What it means | Example use |
| --- | --- | --- |
| `<strong>` | Strong importance or urgency | Important warning |
| `<b>` | Draw attention without adding importance | A keyword in a summary |
| `<em>` | Stress emphasis | Emphasizing *today* instead of tomorrow |
| `<i>` | Different voice or conventional designation | A scientific name |
| `<u>` | Non-textual annotation | Marking a spelling error |
| `<small>` | Side comment or fine print | Disclaimer |
| `<mark>` | Text relevant in the current context | A highlighted search match |

**Remember:** These are not interchangeable style shortcuts. For purely visual bold, italic, or underline effects, use CSS when you learn it.

Examples:

```html
<p><strong>Important:</strong> Bring your appointment confirmation.</p>
<p>Please arrive <em>before</em> your scheduled time.</p>
<p>Search result: <mark>general consultation</mark>.</p>
<p><small>Example clinic — not real medical advice.</small></p>
```

## 4. Build a simple web page

Type the following into `index.html` and open it in your browser:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="description" content="Opening hours and information for a demo clinic.">
  <title>Visitor Guide | Demo Clinic</title>
</head>
<body>
  <h1>Demo Clinic — Visitor Guide</h1>

  <h2>Opening Hours</h2>
  <p>Monday to Friday: 9 AM to 5 PM.</p>
  <p><strong>Important:</strong> Please arrive <em>10 minutes early</em>.</p>

  <h2>Contact Information</h2>
  <p>Demo Clinic<br>Hyderabad, India</p>

  <hr>
  <p><small>This is a fictional page for HTML practice.</small></p>
</body>
</html>
```

**Observe:** The browser tab displays the `title`, while the page displays the `h1`. The `br` breaks the address into two lines; the `hr` marks a change from visitor details to a footer-like note.

## 5. Hands-on task — Student Information Page

Build a page about a **fictional student or course** using HTML only. Don't copy the clinic example unchanged.

**Requirements:**

- Correct document structure, `lang`, `charset`, `title`, and meta description.
- One `h1`, at least two `h2` headings, and three meaningful paragraphs.
- At least one appropriate use of `strong` and one of `em`.
- Use `small`, `mark`, `br`, or `hr` **only when the meaning fits**; do not add tags just to increase the count.

**Expected result:** A readable page whose sections make sense even without CSS.

**Stretch challenge:** Add an `h3` subsection and explain why it belongs under an `h2`.

**Acceptance checklist:**

- [ ] My headings follow a sensible hierarchy.
- [ ] I used tags for meaning, not just appearance.
- [ ] The title in the browser tab matches the page topic.
- [ ] I can explain every tag I used.

## 6. Common mistakes and quick check

Avoid using heading levels to change font size, repeated `<br>` tags to create spacing, or `<strong>` for purely decorative bold text. CSS will handle styling later.

Before moving on, answer:

1. Why is `<h2>Services</h2>` better than `<p><b>Services</b></p>` for a real section heading?
2. When would you choose `<strong>` instead of `<mark>`?
3. Why shouldn't you use `<br>` to create large gaps?
4. Does adding a meta description guarantee a Google ranking? Why not?
