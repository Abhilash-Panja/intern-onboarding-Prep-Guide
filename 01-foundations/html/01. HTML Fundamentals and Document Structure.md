# Day 1 — HTML Fundamentals

**Goal:** Understand HTML and create your first web page.  
**Prerequisites:** A text editor and a web browser.  
**Suggested time:** 45–60 minutes, including practice.

## 1. Why do we need HTML?

Imagine creating a clinic website. You need a page title, opening hours, and a message for visitors. The browser needs to know **which content is a heading and which is a paragraph**.

**HTML (HyperText Markup Language)** describes the content and structure of a web page. CSS controls its appearance; JavaScript adds behavior.

| Technology | Main responsibility |
| --- | --- |
| HTML | Structure and meaning — heading, paragraph, image, link |
| CSS | Appearance and layout — color, spacing, alignment |
| JavaScript | Behavior — respond to clicks and update content |

## 2. Tags, elements, and attributes

```html
<p>Welcome to our clinic.</p>
```

- `<p>` is an **opening tag**.
- `Welcome to our clinic.` is its content.
- `</p>` is the **closing tag**.
- The entire line is a **paragraph element**.

An **attribute** adds information to an opening tag:

```html
<html lang="en">
```

Here, `lang="en"` identifies English as the page's primary language. Not every HTML element has a closing tag: `<meta>` and `<br>` are examples of **void elements**.

## 3. Basic HTML document

Create a file named `index.html` and type this code:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Web Page</title>
</head>
<body>
  <h1>Welcome to My Clinic</h1>
  <p>We are open from 9 AM to 5 PM.</p>
</body>
</html>
```

| Part | What it does |
| --- | --- |
| `<!DOCTYPE html>` | Helps the browser use standards mode; it is not an HTML element |
| `<html>` | Root element of the document |
| `<head>` | Information about the document, usually not page content |
| `<meta charset="UTF-8">` | Declares the document's character encoding |
| `<title>` | Sets the text commonly shown in the browser tab |
| `<body>` | Contains the page's main document content |
| `<h1>` | Marks a top-level heading |
| `<p>` | Marks a paragraph |

**Try it:** Save the file, double-click it to open it in your browser, and compare the text on the page with the text in the browser tab.

**Remember:** HTML elements form a tree. In the example, `head` and `body` are children of `html`; `h1` and `p` are children of `body`.

## 4. Hands-on task — About Me page

Create `about-me.html` **without copying the example line for line**.

Your page must contain:

- A suitable browser-tab title.
- One main heading with your name or a fictional name.
- Two paragraphs: an introduction and what you want to learn.
- A correctly structured `html`, `head`, and `body`.

**Expected result:** The browser displays one heading and two paragraphs; the tab displays your chosen title.

**Self-check:**

- [ ] My file opens in a browser.
- [ ] The page heading and browser-tab title are different and appropriate.
- [ ] I can explain what each structural tag does.
- [ ] My HTML is nested correctly.

## 5. Quick check

1. How are HTML, CSS, and JavaScript different?
2. What is the difference between a tag and an element?
3. Where should the browser-tab title go: `head` or `body`?
4. What happens if you change the text inside `h1`?

**Common mistakes:** Forgetting closing tags where required, placing visible text in `head`, and saving the file as `.txt` instead of `.html`.
